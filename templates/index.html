📊 Data Type Functions

1. is_adult(age) Integer → Boolean

True if age ≥ 18. Negative age raises ValueError.

2. celsius_to_fahrenheit(c) Float → Float

Convert °C to °F, rounded to 2 decimals.

3. count_vowels(text) String → Integer

Count vowels (a,e,i,o,u), case-insensitive. Non-string raises TypeError.

4. invert(flag) Boolean → Boolean

Return the opposite. Non-bool raises TypeError.

5. greet(name) String/None → String

Greet by name; defaults to "Guest" if empty/None.

6. find_max(numbers) List → Number

Return largest number. Empty list raises ValueError.

7. get_price(prices, item) Dict, String → Number

Return price of item. Missing key raises KeyError.

8. swap(pair) Tuple → Tuple

Swap two values. Not exactly 2 raises ValueError.

9. common_items(a, b) Set, Set → Set

Return items found in both sets.

10. is_leap_year(year) Integer → Boolean

True if year is a leap year. Year < 1 raises ValueError.

11. to_int(value) Any → Integer

Convert to int. Bool raises TypeError.

🔢 Math Functions

12. divide(a, b) Math

Return a / b. Division by zero raises ZeroDivisionError.

13. power(base, exp) Math

Return base raised to exponent.

14. square_root(x) Math

Return √x. Negative raises ValueError.

15. factorial(n) Math

Return n!. Negative raises ValueError.

16. average(numbers) Math

Return mean of list. Empty raises ValueError.
